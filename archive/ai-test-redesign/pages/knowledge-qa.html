用户登录认证流程中，密码加密使用的是什么算法？

用户登录认证流程中，密码加密使用的是 bcrypt 算法，加盐次数为 12 轮。bcrypt 是一种自适应密码哈希函数，通过增加计算成本来抵抗暴力破解攻击，同时内置盐值机制防止彩虹表攻击。

import bcrypt

# 加盐次数为 12 轮
password = b"user_password"
salt = bcrypt.gensalt(rounds=12)
hashed = bcrypt.hashpw(password, salt)
# stored hashed in database

支付接口的签名算法是怎样的？能否举个例子？

支付接口使用 HMAC-SHA256 算法进行签名。具体流程为：将请求参数按字典序排序后拼接成签名字符串，再使用密钥进行 HMAC-SHA256 计算得到签名值，最终将签名附加在请求参数中一并发送。

import hmac
import hashlib

def generate_signature(params, secret_key):
    sorted_params = sorted(params.items())
    sign_string = "&".join(f"{k}={v}" for k, v in sorted_params)
    signature = hmac.new(
        secret_key.encode(),
        sign_string.encode(),
        hashlib.sha256
    ).hexdigest()
    return signature
