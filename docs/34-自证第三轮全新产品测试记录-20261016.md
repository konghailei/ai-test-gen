## 3. 发现与观察

### 3.1 执行器/环境级问题（非系统缺陷）

1. **计划日志 0 字节**：`logs/plan-20261016-030552.log` 为 0 字节。执行器 stdout 重定向
   在进程被回收时来不及 flush。→ **建议**：执行器改为**行缓冲/带 flush 的日志写入**，
   或在 `main()` 里 `sys.stdout.reconfigure(line_buffering=True)`，避免中断即丢日志。
2. **后台任务随会话回收**：以会话后台任务方式启动的长流程，在会话中断后进程消失。
   → **建议**：长流程测试用独立方式启动（`nohup`/`setsid` 或独立终端），
   或执行器自带 **断点续跑**（记 progress 文件），中断后从 L2 续起。
