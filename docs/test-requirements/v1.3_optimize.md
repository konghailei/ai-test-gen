# 项目管理系统 - 历史版本管理模块 优化需求 v1.3

> 版本：v1.3 | 基于 v1.2 优化 | 模块：版本管理 | 对应测试阶段：阶段2/3 项目4

## 1. 简介

本版本新增「批量导入历史版本」功能，支持从外部系统批量导入历史版本数据。同时引用 v1.2 的敏感词校验策略。

## 2. 用户故事

- 作为 项目经理，我希望 批量导入外部系统的历史版本数据，以便 快速迁移项目资料。
- 作为 团队成员，我希望 导入的版本能自动应用现有的敏感词校验策略，以便 保证数据合规。

## 3. 功能描述

### 3.1 批量导入历史版本

新增功能：批量导入历史版本

- 支持格式：CSV / Excel（xlsx）/ JSON
- 单次导入上限：1000 条版本记录
- 导入字段映射：外部字段 → 系统字段的映射规则
- 导入冲突处理：版本编号重复时跳过并记录日志
- 导入进度显示：实时显示已导入/总数/失败数

### 3.2 图片上传功能

沿用现有图片上传规则（保持不变，本次不改动）。

> **模糊引用**：应从 v1.0 KB 命中图片上传规则全集。

### 3.3 敏感词校验

导入的版本数据中，文件名、描述字段需经过敏感词校验。

沿用现有敏感词校验策略。

> **模糊引用**：应从 v1.2 KB 命中"敏感词库从三级分类调整为两级分类"。

### 3.4 版本保留策略

沿用 v1.1 的版本保留策略调整。

## 4. 权限

权限控制沿用现有历史版本模块的权限控制规则。

> **模糊引用**：应从 v1.0 KB 命中权限定义。

## 5. 验收标准

**AC-01**：上传 CSV/Excel/JSON 格式的批量导入文件应成功解析。
**AC-02**：单次导入 1001 条记录，仅前 1000 条成功，第 1001 条返回"超过单次导入上限"。
**AC-03**：导入版本编号重复的记录，跳过并记录日志。
**AC-04**：导入过程中文件名含一级敏感词的记录，拒绝导入并返回"内容违规，请修改后重试"。
**AC-05**：导入进度实时显示已导入/总数/失败数。

## 6. 优化影响范围

本次优化涉及以下历史数据迁移：

- 外部系统历史版本数据迁移至本系统
- 迁移过程中需应用 v1.2 的敏感词校验策略

> **优化影响配套问题**：应生成 kb_optimization_impact + kb_optimization_impact_scope 两条配套问题。
