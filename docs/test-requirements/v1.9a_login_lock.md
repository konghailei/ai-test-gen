# 项目管理系统 - 系统登录安全策略 需求文档 v1.9a

> 版本：v1.9a | 模块：登录安全 | 对应测试阶段：阶段7 版本变更覆盖（变更前基线）

## 1. 简介

本需求定义系统登录安全策略，重点定义登录失败锁定机制，防止暴力破解攻击。

## 2. 用户故事

- 作为 系统用户，我希望连续登录失败后账号被锁定，以便 保护账号安全。
- 作为 系统管理员，我希望锁定时间可配置，以便 平衡安全与用户体验。

## 3. 功能描述

### 3.1 登录失败锁定

- 用户连续登录失败 **5 次** 后，账号进入锁定状态
- 锁定时长为 **1 分钟**
- 锁定期间禁止该账号登录，系统提示「账号已锁定，请 1 分钟后再试」
- 锁定到期后账号自动解锁，无需人工干预

### 3.2 锁定提示

- 锁定期间尝试登录时，提示剩余锁定时间
- 锁定解除后，失败计数清零

### 3.3 密码错误处理

- 登录失败时记录失败次数，并提示剩余可尝试次数
- 密码错误提示不区分"用户名不存在/密码错误"，避免账号枚举

## 4. 验收标准

**AC-01**：连续登录失败 5 次触发账号锁定。
**AC-02**：锁定时长 1 分钟。
**AC-03**：锁定期间登录被拒绝，并提示剩余锁定时间。
**AC-04**：1 分钟后自动解锁，失败计数清零。

## 5. 优化影响范围

- 涉及用户账号安全策略调整，不影响历史版本数据。
- 需确认是否影响现有用户会话（已登录用户是否失效）。
