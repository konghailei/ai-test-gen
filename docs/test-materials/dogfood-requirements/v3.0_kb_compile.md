# 项目管理系统 v3.0 需求文档（知识库编译化：最新整理版与自检）

> 产品：AI 测试用例生成平台
> 项目版本：v3.0（增量优化——知识库编译化）
> 优先级：P1
> 与 v2.0 的关系：本版本为 v2.0 基础上的增量变更。未提及的需求沿用 v2.0（其沿用链上溯至 v1.0）。

---

## 1. 变更概述

针对知识库"同名功能点跨版本知识分散"问题，本版本引入**功能点最新整理版**（编译聚合知识，下称"整理版"）与**知识库周期自检**两项能力，实现"检索内容优先返回最新整理的知识"，并防止编译知识随版本累积而腐化。

## 2. 变更点详述

### 2.1 功能点最新整理版（CRSR）—— 编译聚合（增强 v2.0 §3.9.2）

2.1.1 归档与知识纠错时，系统将同名功能点的跨版本知识聚合为该功能点的"最新整理版"：

- 标量字段（如描述、单一数值约束）：取版本时间最新的值；
- 列表字段（如业务规则、备选流程）：按条目标识去重后合并各版本的条目（同一标识的条目取最新版本内容，不同标识的条目并集保留）。

2.1.2 整理版是编译产物而非权威记录：权威知识始终是各版本的原始需求结构；整理版必须可随时重算，且保留版本来源链（每条聚合知识可追溯来自哪个版本）。

2.1.3 聚合在归档/纠错事务中同步触发；聚合失败不阻断归档主流程，但须记录标记。

### 2.2 整理版向量入库（新增）

2.2.1 聚合成功后，整理版内容向量化写入知识库向量库。向量标识为确定性生成（由产品与功能点名称派生），同一功能点重复归档时**覆盖更新**同一条向量，不产生堆积。

2.2.2 整理版向量的元数据必须包含：类型标记（fp_crsr）、归档状态标记（archived）、产品标识、功能点名称、聚合的版本数量、最新版本来源、固化时间。元数据缺失类型或归档状态标记的向量不得进入检索结果（检索按归档状态硬过滤）。

2.2.3 各版本原始向量保留不删除（权威层语义，支持回溯）。

2.2.4 整理版入库走事务性出箱机制（沿用 v1.0 §3.7.3 的可靠投递语义）：入库意图与业务数据同事务提交，后台至少一次幂等投递。

### 2.3 检索与问答采信规则（增强 v2.0 §3.9.4/3.9.5）

2.3.1 知识库问答与澄清补全的检索结果中，整理版条目作为独立类型出现，来源标注为"功能点名（最新整理版，聚合 N 个版本）"，权威层级归属功能点层。

2.3.2 采信规则：整理版与单版本记录内容冲突时，**优先采信整理版并在答案中标注**；检索结果无整理版条目时，沿用"多版本以上线时间靠后为准"的兜底规则。

2.2.3 补充：整理版功能可通过配置开关灰度控制其进入检索结果（默认开启）；关闭开关不影响原始版本知识的检索。

2.3.4 范围限定：澄清环节的知识自动补全维持需求级检索口径（doc_type=requirement），**不引入**整理版条目——补全粒度须与需求级一致，功能点粒度的整理版混入会导致补全粒度错乱。这是有意设计，非遗漏。

### 2.4 知识库周期自检（增强 v2.0 §3.9.7）

2.4.1 自检频率默认每日一次，可配置。三项检查全部只读，产出报告，不自动修改数据：

| 检查项 | 内容 | 产出 |
|---|---|---|
| 整理版漂移 | 对每个功能点重算聚合结果，与已固化数据逐字段比对 | 漂移清单（归档时聚合未触发/失败导致） |
| 跨版本规则矛盾 | 同名功能点各版本知识中：同一规则标识对应不同内容、同一约束字段对应不同限制 | 矛盾清单（冲突双方内容与各自来源版本） |
| 向量对账 | 向量库条目与关系库权威数据对账 | 孤儿向量清单 |

2.4.2 漂移与孤儿的修复动作（重新聚合+重新投递、清除孤儿向量）须人工确认后执行，系统不自动修复。

2.4.3 跨版本矛盾清单作为后续"矛盾标注产品化"（在整理版中标注矛盾提示）的数据源；本版本仅输出报告。

2.4.4 自检过程异常时跳过本轮，不影响主业务（fail-open）。

### 2.5 版本变更覆盖（验证要点，行为沿用）

结合 v1.0 §3.9.4（按最新版本回答）与本版本整理版机制，知识库问答对以下场景的正确行为：

- 同一功能点规则在 v_A 版本为"1-200 字符"、v_B 版本改为"1-500 字符"：问答应回答 500（最新），来源为整理版（聚合 2 个版本）并标注；
- 整理版未生成时：回答 500，来源为 v_B 原始记录（时间靠后兜底）；
- 各版本原始向量均在库，但排序上最新版本知识优先。

## 3. 验收标准

- 归档后向量库出现该功能点的整理版向量，元数据齐全（类型/归档状态/产品/功能点名/版本数）。
- 同一功能点再次归档（第二版本）后，整理版向量被覆盖更新而非新增（向量总数不膨胀）。
- 知识库问答"XX 功能的 XX 规则是什么"命中整理版来源并标注"最新整理版，聚合 N 个版本"。
- 版本变更场景（数值修改）问答返回最新值。
- 自检报告能检出人为构造的漂移（固化数据被篡改）与矛盾（两版本规则冲突）。
- 灰度开关关闭后，检索结果不出现整理版条目，原始版本检索不受影响。
