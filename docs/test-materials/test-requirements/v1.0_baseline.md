# 项目管理系统 - 历史版本管理模块 PRD v1.0（基线版本）

> 版本：v1.0 | 上线日期：2026-08-15 | 模块：版本管理 | 对应测试阶段：阶段2/3 项目1

## 1. 简介

本需求为「项目管理系统 - 历史版本管理模块」v1.0 功能定义。后续优化需求会引用本需求中定义的规则，用于验证归档后 KB 可检索性。

## 2. 用户故事

- 作为 项目经理，我希望 查看历史版本列表，以便 追溯项目变更历史。
- 作为 团队成员，我希望 上传图片附件到版本记录中，以便 保存设计稿和证据截图。
- 作为 项目经理，我希望 手动标记重要版本，以便 永久保留关键里程碑。

## 3. 功能描述

### 3.1 图片上传功能

图片上传规则明确定义：

- 支持格式：jpg / jpeg / png / webp / gif
- 单文件大小限制：≤ 5MB
- 超限提示文案："文件超过 5MB 上限，请压缩后重新上传"
- 批量上传：单次最多 9 张
- 缩略图生成：上传后自动生成 200x200 缩略图
- 文件名规范：原始文件名保留，特殊字符自动过滤

### 3.2 版本保留策略

版本数量限制明确：

- 手动标记版本最多保留 50 个，超过后最旧的手动标记版本自动降级为普通版本
- 自动保存版本（草稿）最多保留 20 个
- 小修订判定标准：正文改动 < 5%（按字符数计算，含标点符号；表格/图片变更另计为附件变更不计入正文字符比例）
- 版本编号规则：v{年月日}{序号}，如 v20260815001

### 3.3 敏感词校验

敏感词校验规则明确定义：

- 敏感词库分为三级：一级（政治敏感）、二级（商业敏感）、三级（一般敏感）
- 上传的图片素材的文件名、描述字段需经过敏感词校验
- 命中一级敏感词：拒绝上传，返回"内容违规，请修改后重试"
- 命中二级敏感词：允许上传但标记为"待审核"，需项目经理审核通过后才对外可见
- 命中三级敏感词：允许上传但记录日志，不阻断流程
- 敏感词库更新频率：每月一次，由系统管理员维护

### 3.4 权限控制

权限角色定义明确：

- 项目经理：可创建/归档版本、可上传图片、可审核敏感内容
- 团队成员：可查看版本、可上传图片、不可归档版本
- 访客角色：仅可查看公开版本，不可上传任何素材，不可查看内部版本

## 4. 流程描述

### 4.1 Happy Path（正常上传流程）

1. 用户在版本详情页点击"上传图片"按钮
2. 系统弹出文件选择器，用户选择 1-9 张图片
3. 系统逐张校验：格式、大小、文件名敏感词
4. 校验通过后，系统生成缩略图并上传到对象存储
5. 系统返回上传成功消息，版本记录中新增图片附件条目

### 4.2 异常流程

- 格式不支持：返回 400"格式不支持，仅接受 jpg/jpeg/png/webp/gif"
- 文件超限：返回"文件超过 5MB 上限，请压缩后重新上传"
- 一级敏感词命中：返回"内容违规，请修改后重试"
- 网络中断：保留本地草稿，提示"网络异常，已为您保留草稿"

## 5. 验收标准

**AC-01**：上传 jpg/png/webp/gif 格式、单文件 <5MB 的图片应成功，返回 200。
**AC-02**：上传 6MB 文件应返回「文件超过 5MB 上限，请压缩后重新上传」。
**AC-03**：手动标记版本累计 50 个后，标记第 51 个时最旧的标记版本自动降级为普通标记。
**AC-04**：上传 docx/txt 等非图片格式，返回 400「格式不支持」。
**AC-05**：访客角色上传图片，返回 403「无权限」。
**AC-06**：上传文件名含一级敏感词的图片，返回「内容违规，请修改后重试」。
**AC-07**：批量上传 10 张图片，仅前 9 张成功，第 10 张返回「单次最多 9 张」。
**AC-08**：正文改动 4%（<5%）的版本被判定为小修订，不生成新版本号。
