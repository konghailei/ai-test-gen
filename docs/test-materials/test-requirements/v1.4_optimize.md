# 项目管理系统 - 历史版本管理模块 优化需求 v1.4

> 版本：v1.4 | 基于 v1.3 优化 | 模块：版本管理 | 对应测试阶段：阶段2/3 项目5

## 1. 简介

本版本新增「版本对比」功能，支持两个版本的差异对比。同时引用 v1.0 的图片上传规则和 v1.2 的敏感词校验策略。

## 2. 用户故事

- 作为 项目经理，我希望 对比两个版本的差异，以便 评估变更影响。
- 作为 团队成员，我希望 对比结果能高亮显示变更内容，以便 快速定位修改点。

## 3. 功能描述

### 3.1 版本对比功能（新增）

新增功能：版本对比

- 对比方式：选择两个版本，系统自动对比差异
- 对比维度：正文内容、附件清单、元数据（作者/时间/标签）
- 差异展示：新增内容绿色高亮、删除内容红色高亮、修改内容黄色高亮
- 对比结果导出：支持导出为 PDF / Markdown / HTML
- 对比历史：保留最近 20 次对比记录

### 3.2 图片上传功能

沿用现有图片上传规则（保持不变，本次不改动）。

> **模糊引用**：应从 v1.0 KB 命中图片上传规则全集：格式 jpg/jpeg/png/webp/gif、单文件 ≤5MB、超限提示文案、批量 9 张、缩略图 200x200、文件名规范。

### 3.3 敏感词校验

沿用现有敏感词校验策略。

> **模糊引用**：应从 v1.2 KB 命中"敏感词库从三级分类调整为两级分类"。

### 3.4 批量导入历史版本

沿用 v1.3 的批量导入功能：支持 CSV/Excel/JSON 格式、单次 1000 条、冲突跳过并记录日志。

> **模糊引用**：应从 v1.3 KB 命中批量导入功能定义。

### 3.5 版本保留策略

沿用 v1.1 的版本保留策略调整。

## 4. 权限

权限控制沿用现有历史版本模块的权限控制规则。

> **模糊引用**：应从 v1.0 KB 命中权限定义。

## 5. 验收标准

**AC-01**：选择两个版本进行对比，系统返回差异结果。
**AC-02**：对比结果中新增内容绿色高亮、删除内容红色高亮、修改内容黄色高亮。
**AC-03**：导出对比结果为 PDF/Markdown/HTML，文件可正常打开。
**AC-04**：对比历史保留最近 20 次记录，超过后最旧记录被覆盖。
**AC-05**：沿用的图片上传规则、敏感词校验规则、批量导入规则均与现网一致。

## 6. 优化影响范围

本次优化涉及以下历史数据迁移：

- 历史版本对比数据需初始化对比基线
- 已有版本的差异索引需重建

> **优化影响配套问题**：应生成 kb_optimization_impact + kb_optimization_impact_scope 两条配套问题。
