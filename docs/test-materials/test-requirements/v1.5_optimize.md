# 项目管理系统 - 历史版本管理模块 优化需求 v1.5

> 版本：v1.5 | 基于 v1.4 优化 | 模块：版本管理 | 对应测试阶段：阶段2/3 项目6

## 1. 简介

本版本调整权限模型，引入「审核员」角色，分担项目经理的审核负担。同时引用 v1.4 的版本对比功能和 v1.0 的图片上传规则。

## 2. 用户故事

- 作为 系统管理员，我希望 新增「审核员」角色，以便 分担项目经理的审核负担。
- 作为 审核员，我希望 我能审核二级敏感词命中的素材，以便 加快审核流程。
- 作为 项目经理，我希望 我能把审核权限委派给审核员，以便 我专注于项目决策。

## 3. 功能描述

### 3.1 权限模型调整

新增角色：审核员

- 审核员权限：可审核二级敏感词命中的素材、可查看所有版本、不可创建/归档版本、不可上传图片
- 项目经理权限调整：可创建/归档版本、可上传图片、可审核敏感内容、可委派审核权限给审核员
- 团队成员权限不变：可查看版本、可上传图片、不可归档版本
- 访客角色权限不变：仅可查看公开版本，不可上传任何素材

> **新增项**：v1.0 中只有项目经理/团队成员/访客三种角色，本版本新增「审核员」角色。

> **矛盾点**：v1.0 规定"项目经理：可审核敏感内容"，本版本允许审核员分担审核，但项目经理仍保留审核权限。应检测权限边界变化。

### 3.2 版本对比功能

沿用 v1.4 的版本对比功能：选择两个版本对比差异、三色高亮、导出 PDF/Markdown/HTML、保留最近 20 次对比记录。

> **模糊引用**：应从 v1.4 KB 命中"版本对比功能"定义。

### 3.3 图片上传功能

沿用现有图片上传规则（保持不变，本次不改动）。

> **模糊引用**：应从 v1.0 KB 命中图片上传规则全集。

### 3.4 敏感词校验

沿用 v1.2 的两级敏感词校验策略。

> **模糊引用**：应从 v1.2 KB 命中"敏感词库从三级分类调整为两级分类"。

### 3.5 批量导入历史版本

沿用 v1.3 的批量导入功能。

### 3.6 版本保留策略

沿用 v1.1 的版本保留策略调整。

## 4. 验收标准

**AC-01**：审核员登录后，可查看所有版本列表。
**AC-02**：审核员尝试上传图片，返回 403「无权限」。
**AC-03**：审核员可审核二级敏感词命中的素材，审核通过后素材对外可见。
**AC-04**：项目经理可委派审核权限给审核员，委派后审核员立即获得审核权限。
**AC-05**：沿用的版本对比功能、图片上传规则、敏感词校验策略均与现网一致。

## 5. 优化影响范围

本次优化涉及以下历史数据迁移：

- 现有项目经理的审核记录保留，不迁移
- 新增审核员角色后，需为现有项目分配默认审核员（如有）

> **优化影响配套问题**：应生成 kb_optimization_impact + kb_optimization_impact_scope 两条配套问题。
