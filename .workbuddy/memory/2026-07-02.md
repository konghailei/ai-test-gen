## 依赖图谱优化（2026-07-06）

**第一次**: 双栏布局重设计，节点手柄连线，全视口画布
**第二次**: 修复 edge API 422（query params → JSON body），模块添加改为下拉框
**第三次**: 不能新增/删除模块（模块管理在「产品与项目」页）；删除节点=从图谱移除不删DB；工具栏拖拽模块→模块选择器；双击→搜索切换模块

**痛点**: 旧版依赖图谱使用拖拽式工具栏，交互不直观，画布空间小(560px)。

**改进**:
- 采用双栏布局：左侧 260px 模块库 + 右侧全视口高度画布
- 左侧栏: 搜索过滤 + 点击添加模块 + 内联新建 + 图例
- 节点添加连接手柄（Handle），拖拽手柄连线替代"连线模式"按钮
- 点击连线显示信息面板（可删除）
- 画布全高度 `h-[calc(100vh-5rem)]`
- 键盘快捷键: Del 删除选中, Esc 关闭全屏
- 选中节点高亮(ring)，右键菜单优化
- 自动布局算法（网格排列）

**根因**: `Layout.tsx` 中 `useProduct()` 在 `ProductProvider` 外部调用。

```
Layout 执行顺序：
  1. useProduct() ← 此时 ProductProvider 未渲染，拿到默认空值
  2. return <ProductProvider> ← Provider 才开始渲染（太晚了）
```

**修复**:
- `App.tsx`: 将 `ProductProvider` 提升到 App 级别，wrap 整个 `Layout`
- `Layout.tsx`: 移除内部重复的 `ProductProvider`，只保留 `useProduct()`
