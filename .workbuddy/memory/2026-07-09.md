## 部署方法
```bash

docker compose down
docker compose up -d

# 首次部署需要等 minio + etcd healthy → milvus 启动 → backend 连接
# milvus start_period=60s，首次全链路就绪约 2-3 分钟
docker compose logs -f milvus  # 观察启动
```
